Apelin 0.3.8 brings everything up to 0.3.7 and lowers the minimum system to iOS 15.0, so a jailbroken iPhone or iPad that stayed on iOS 15 can run the IDE, create projects and build on the device.

- Creating a tweak, app, command-line tool or preference bundle failed with `deploymentTarget: "15.0" is not a valid deploymentTarget`. The template check accepted 15.0 nowhere, so no SDK-backed project could be made on iOS 15. It now accepts 15.0 and later, while still refusing anything below.
- The app and its tools are packaged for iOS 15.0 instead of 16.0: the deployment floor, the project default and the Debian dependency moved from 16.0 to 15.0.
- A share sheet, the sidebar menus and a few other places used iOS 16-only APIs; they are replaced or guarded so the app runs on iOS 15.
- Files picked from iCloud Drive are downloaded and read through file coordination, so an attachment that had not been downloaded locally no longer imports empty.

This release also carries 0.3.5 to 0.3.7 from upstream: the Chinese translations read like the system's own words, projects and conversations survive a rootless install and a restart, a conversation can send again after its approval was cut off, Apelin says up front that it cannot build on roothide Bootstrap, tweaks can hook Apelin's own classes, and Antigravity joined Model Providers.

Requires iOS or iPadOS 15.0 or later, an A12 chip or later, Irisin 4.7.3 or later and icli 0.10.0 or later. Choose the `iphoneos-arm64e` packages for RootHide or the `iphoneos-arm64` packages for rootless, and check each download against `SHA256SUMS`.
